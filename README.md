# Flow Radar · 美股资金雷达 v3

这是一个手机友好的**双层 ETF 资金/量价 + 联动研判网页**。不需要券商账号或个人持仓。纯前端静态项目，可部署到 GitHub Pages（HTTPS）并在手机桌面打开。

## 两个监测层

| 模块 | 更新节奏 | 数据 / 指标 | 代表什么 / 不代表什么 |
|--|--|--|--|
| 收盘资金流 | 每个美股交易日盘后（依源数据时间戳） | ETFIQ 的 ETF 净申赎：股票/债券/商品分类、分类轮动、指定基金，1D/1W/1M/3M/YTD/1Y | ETF 基金份额净创建/赎回的估计，不等于二级市场买卖的资金净流入 |
| 盘中量价信号 | 常规交易时段约每根5分钟K线后可刷新（供应商可能延迟） | 主要板块与指数 ETF 当日涨跌幅、成交额估算、与历史同时段比较的 RVOL、放量上涨/下跌 | 反映价格与成交量，不代表机构净流入，也不包含暗池和期权资金 |

### 双层联动（新增）

在“盘中量价信号”页面先点「获取盘中信号」，然后点「更新双层联动」。联动仅比对同一只 ETF 的基金净申赎和最近有效5分钟量价数据，默认取最近 **1W** 基金申赎（可切换1D、1M、3M），日内价格必须变化至少 ±0.20%，至少3天 RVOL 基准样本，申赎方向明确，最近行情不能早于纽约当前日期4天，两层日期间隔最多7个自然日，且不能是断网过期行情/申赎缓存。满足后标注资金与价格同向或背离；RVOL ≥ 1.5 为“放量”。

**证据匹配分**仅为启发式规则：资金与价格同向时 `45 + 30*min(|当日涨跌%|/1.5,1) + 25*clip((RVOL-0.7)/0.8,0,1)`，四舍五入为0–100；方向背离或数据不全则不评分。评分不是上涨/下跌概率或收益预测。不同日期的 ETF 净申赎与行情 **绝不代表同一时刻的资金交易**。源方只给总 as-of 而不给每只基金窗口结束日时，界面会标明这一限制。

### RVOL 方法
以纽约时间为准，过滤掉盘前/盘后，仅取 `09:30 ≤ bar_time < 16:00` 的5分钟K线。
RVOL = 最新交易日从开盘到最近已完成时段的累计成交量 / 历史最多10个交易日在**相同日内时刻**累计成交量的平均值；需要至少3天可比样本（且历史覆盖不少于当前K线根数的 75%）。显示 `RVOL ≥ 1.50` 为放量，涨跌超过 ±0.05% 分为上涨/下跌。没有足够历史样本则显示“—”。

成交额**估算** = ∑(各根5分钟收盘价 × 该根成交量)。这是成交额 proxy，不能换算“净买入”。日内涨跌 = 最近有效常规时段收盘 / 上个交易日最后一根常规时段收盘 - 1（未计股息）。

## 数据源与限制

- [ETFIQ 开放数据](https://etfiq.com/data/): `https://etfiq.com/data/flows/aggregates.json` 与 `flows/funds/{ticker}.json`，实际净申赎在盘后才能统计；需遵守数据源许可及其覆盖限制。
- [TickerInside API](https://tickerinside.com/api/): `https://tickerinside.com/api/v1/flows.json`，部分 ETF 持仓变动，不是个股实际资金净买盘。
- **免费盘中模式（默认）**：通过 [cors.dev](https://cors.dev/docs) 向 Yahoo Finance **非官方** v8 chart API 请求 `range=1mo&interval=5m` 的公开行情。仅用于个人实验监控；上游可随时限流、结构变更或停止。使用代理会使该服务知道请求的标的代码与 IP 等网络信息。
- **官方盘中模式（可选）**：填写个人 [Twelve Data API Key](https://twelvedata.com/pricing)，调用 `time_series` (5min)，免费档通常 8 credits/min、800 credits/day。页面最多取8只 ETF，控制每次最多2路并行。自动刷新默认关闭；如开启会在浏览器前台、美东常规开市时至少隔5分钟刷新（约8只每5分钟，可能超过日额度，因此谨慎启用）。
- Yahoo 和 Twelve Data 数据时间及交易所覆盖不一定相同。**页面显示 K 线真实截至时间；不会自称交易所逐笔实时**。周末、节假日也可能显示最近交易日。
- 在纯前端网页中使用 API Key 会暴露给用户设备及浏览器开发者工具。默认只保留到刷新页面为止，勾选“保存”后会以明文存于本机浏览器 localStorage。请勿在公共电脑保存，也不要嵌入共享站点的前端源码。
- 所有行情须实际网络浏览器验证；开发容器无法直连外部数据接口。若源失效，页面提示失败或缓存，**不产生虚构结果**。

## iPhone 安装：GitHub Pages

1. 在 GitHub 建立一个公开仓库，如 `us-flow-radar`。
2. 将本文件夹中的 **`index.html`、`intraday.js`、`fusion.js`、`manifest.webmanifest`、`sw.js`、`icon.svg`** 上传到仓库根目录。（`test.html` 和本地测试脚本可不上传。）
3. 在仓库 `Settings` → `Pages` → `Deploy from a branch`，选 `main` 和 `/(root)`，保存并打开 GitHub Pages 提供的 HTTPS 链接。
4. 在 iPhone Safari 打开该链接，使用“分享”→“添加到主屏幕”。
5. 顶部两个大按钮可切换“收盘资金流”和“盘中量价信号”；默认盘中模式不需要 Key。

网站只是数据读取器，不会后台一直监视市场；当网页关闭，自动刷新不会运行，也不会自动推送通知。
